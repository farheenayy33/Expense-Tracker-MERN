# Expense Tracker

A modern full-stack expense management application built with the MERN stack. Manage income and expenses, track your balance, and view transaction history through a responsive dashboard.

## Features

- User registration and login
- Add income and expenses
- Automatic balance and savings calculation
- User-specific transaction data
- Transaction history and recent activity
- Responsive dashboard
- Secure password hashing

## Tech Stack

**Frontend:** React, Vite, Tailwind CSS, Redux Toolkit, TanStack Query, Axios, React Router, Framer Motion, Zod

**Backend:** Node.js, Express.js, Mongoose, bcrypt

**Database:** MongoDB Atlas

## Installation

Clone the repository:

    git clone <your-repository-url>
    cd Expense-Tracker

### Frontend

    cd Frontend
    npm install
    npm run dev

### Backend

    cd backend
    npm install
    npm run dev

## Environment Variables

Create a `.env` file inside the `Server` directory:

    PORT=5000
    MONGO_URI=your_mongodb_connection_string
